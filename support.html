❓ 常见问题 FAQ

Zipease 支持哪些压缩/解压格式？

支持 ZIP / 7Z / RAR / TAR / GZ / BZ2 / XZ / LZMA / CAB / ISO / WIM / Z / LZ4 / ZSTD / APK 等 15+ 种主流格式解压；压缩支持 ZIP、7Z、TAR、TAR.GZ、TAR.BZ2、TAR.XZ 六种，均支持 AES-256 强度加密。

Zipease 保存的密码存在哪里？会被上传吗？

绝对不会上传。Zipease 把你保存的压缩包密码使用系统级 Keychain（钥匙串）加密存储，全程只在本机读写，不会离开你的 Mac。即使 iCloud 钥匙串开启，加密密钥也由 Apple 的 Secure Enclave 保管，开发者无法读取。

如何设置 Zipease 为某种格式的默认打开方式？

打开 Zipease → 设置 → 格式，找到目标格式（如 ZIP），点击右侧 「设为默认」。macOS 会弹出系统级确认框，确认后即完成绑定。若点击后无反应，请打开 系统设置 → 桌面与程序坞 → 高级设置 检查「默认应用」权限是否已授予 Zipease。

分卷包解压失败，提示「分卷缺失」怎么办？

分卷包（如 .zip.001、.part1.rar、.7z.001）必须所有分片齐全才能完整解压。请检查：
① 所有分片大小正常且数量无缺；
② 所有分片放在同一文件夹下；
③ 文件名命名方式统一（不要手动改名）。
Zipease 会自动识别分卷序列，直接双击第 1 片即可。

解压提示「你没有权限写入目标目录」？

Zipease 运行于 App Sandbox 下，默认无权访问任意目录。请在首次解压时，通过系统弹出的文件选择器显式授权目标路径，或在 系统设置 → 隐私与安全性 → 文件与文件夹 中为 Zipease 勾选对应磁盘权限。

批量处理时某个任务失败了会影响其他任务吗？

不会。每个任务相互隔离执行，失败任务会标红并在任务列表中显示错误原因，其余任务继续执行。完成后可单独重试失败项。

Zipease 会收集我的使用数据吗？

Zipease 完全不收集用户任何数据，不含统计分析 SDK、不含崩溃上报 SDK、不含广告 SDK。所有操作 100% 在本地进行，甚至不需要网络权限（详见隐私政策）。

应用启动提示「Zipease 已损坏，无法打开」？

这是 macOS Gatekeeper 的签名校验保护机制。请确认你是通过 Mac App Store 下载的版本（非官网 DMG 版），MAS 版本由 Apple 官方签名公证，绝不会出现此提示。如果你通过其他渠道获取，请卸载后从 App Store 重新下载安装。

🐞 崩溃日志获取方法

遇到闪退或卡死？把崩溃日志附在反馈邮件/表单里，我们能数小时内定位到问题根源。按下面任一方法即可导出：

方法一：控制台 (Console) 导出（推荐）

1

按 ⌘ 空格 打开聚焦搜索，输入 Console（控制台）并回车。

2

左侧选择 「崩溃报告」（Crash Reports），右侧列表按进程名 Zipease 或时间排序，找到最近一次崩溃。

3

右键报告 → 「在访达中显示」，会得到一个 .ips 后缀的文件，直接拖进邮件或表单附件即可。

方法二：直接从 Finder 定位

1

打开 Finder，按 ⌘ ⇧ G（前往文件夹）。

2

粘贴路径：~/Library/Logs/DiagnosticReports/ 回车。

3

按时间排序，找到以 Zipease- 开头的最新 .ips 文件。

💡 小提示：如果遇到的是「卡死（无响应）」而不是闪退，可在控制台选 「旋转报告 / Spindump」 或 「采样进程」 导出挂起时的堆栈。

🖥 系统要求与安装

  • 最低 macOS 版本：macOS 14.0 Sonoma 及以上（含 macOS 15 Sequoia）。
  • 芯片架构：Apple Silicon（M1 / M2 / M3 / M4 系列）原生支持，同时兼容 Intel x86_64 机型。
  • 磁盘空间：推荐预留 ≥ 100 MB，解压超大归档时需要工作区。
  • 网络：不要求。Zipease 是纯本地应用，不需要网络权限。
  • 唯一安装渠道：Mac App Store（Apple 签名公证，安全可靠）。
