使用教程

从零开始，5 分钟掌握 Zipease 全能力

本教程覆盖 Zipease 全部核心功能：预览解压、加密压缩、批量处理、格式关联、密码钥匙串、损坏文件修复，以及 Pro 版激活与恢复购买。按目录跳转你想了解的章节即可。

🚀 快速入门：30 秒上手

① 拖拽打开

把任意压缩包拖到 Zipease 主窗口或 Dock 图标，立即预览内容。

② 双击打开

在 Finder 中双击任意格式归档（需先在设置里关联格式）。

③ 一键解压

预览窗口右上角「解压」按钮一键导出，或右键选中单独文件。

💡

小提示：首次使用建议先打开 Zipease → 设置…（⌘,）把常用格式关联为默认打开方式，之后 Finder 中双击即可直接预览。

📂 一、预览与解压压缩包

Zipease 支持 ZIP / 7Z / RAR / TAR / GZ / BZ2 / XZ / LZMA / CAB / ISO / WIM / APK 等 15+ 种主流格式预览与解压。

1.1 浏览归档内容

1

将压缩包拖入主窗口 / Dock 图标，或直接使用「文件 → 打开…」（⌘ O）。

2

进入预览面板后，左上搜索框（⌘ F）可按文件名快速过滤，右上角可切换列表/图标视图。

3

单击选中文件后，点击「眼睛图标 👁」即可直接在内嵌面板预览（支持图片 / 文本 / PDF / 音视频 / 代码等），无需先解压。

1.2 解压全部 / 解压选中项

1

点击预览面板顶部「解压」按钮（快捷键 ⌘ E）解压整个归档；或右键选中多个文件后选「解压选中项」。

2

在弹出的目标位置选择器中：「同目录」解压到压缩包所在文件夹；「桌面」直达桌面；「选择解压到…」自定义任意路径。

3

遇到同名文件会弹出冲突处理面板，可单选「覆盖 / 跳过 / 重命名」或「全部覆盖」，全程不丢失文件。

🔒

加密压缩包？打开时会自动弹出密码输入框。如果之前保存过相同归档的密码，会自动从系统钥匙串填充。输错密码会即时提示而不产生损坏文件。密码可点击「💾 保存到钥匙串」复选框记住（详见第六节）。

🔐 二、创建加密压缩包

2.1 通过「压缩文件」功能创建

1

点击主界面「压缩文件」卡片 / 菜单栏文件 → 新建压缩包…（⌘ N），打开压缩面板。

2

点击「添加文件」加入任意文件/文件夹，或直接拖入。右下角可设置：压缩格式（ZIP / 7Z / TAR 系列）、压缩级别（仅存储 / 快速 / 标准 / 最大压缩）。

3

下方「保存位置」可更改输出目录，文件名会自动按主文件名补扩展名。

💎

Pro 版独享功能：AES-256 加密压缩、7Z 格式压缩、文件名加密（-mhe=on）——即使是文件列表也需要密码才能查看，全面保护敏感数据。

2.2 加密选项详解

  • ZIP 加密：默认使用传统 ZipCrypto（兼容性最好，支持跨平台打开）。对兼容性不敏感的用户，建议选 7Z 格式 + AES-256。
  • 7Z 加密：使用 AES-256 强度加密，并额外支持「加密文件名」开关——开启后他人看不到压缩包内部有哪些文件。
  • 密码强度指示：输入密码时下方会实时显示「弱 / 中等 / 强」三档，强烈建议长度 ≥ 10 位，混合字母数字和特殊符号。

📦 三、批量处理（Pro 版）

3.1 批量解压

1

点击主界面「批量处理 → 批量解压」，拖入或选择多个压缩包（支持混合格式）。

2

选择输出模式：「各自解压到同名文件夹」或「全部解压到同一文件夹」，路径可选当前目录/指定文件夹。

3

点击「开始处理」，进度条实时显示每项状态；失败项会单独标红，结束后可单独重试。

3.2 批量压缩

多个文件/文件夹可一次批量打包为独立归档或统一一个大归档；支持同样的加密、格式与级别选项，适合周期性备份场景。

⚙️ 四、设置与文件格式关联

打开 Zipease → 设置…（⌘ ,），面板含「通用 / 格式关联 / 关于」三个标签页。

4.1 通用标签页

  • 默认解压位置：压缩包所在目录 / 桌面 / 下载 / 每次询问，可根据使用习惯提前选定。
  • 解压后自动打开文件夹：开启则解压完成会弹出 Finder 定位结果。
  • 覆盖前确认：关闭后同名冲突将默认覆盖，仅推荐熟悉的用户使用。
  • 文件名编码：遇到中文/日文乱码时，可切换 GBK / GB18030 / Shift-JIS / EUC-JP / Latin1 等重新加载。
  • 应用语言：支持跟随系统 / 简中 / 繁中 / English 等 18 种语言，切换后重启生效。

4.2 格式关联

  • 单击任一格式右侧的「设为默认」，系统会弹出一次确认框，同意后 Finder 双击该格式即会用 Zipease 打开。
  • 点「恢复默认」可还原为 macOS 原先的默认处理程序（如 Archive Utility / BOMArchiveHelper）。
💡

关于系统确认弹窗：macOS 出于安全原因，每种格式的「设为默认」都会单独弹一次系统对话框，请点「确定」。这是系统层的强制机制，任何 App 都无法绕过。

🔑 五、密码管理（系统钥匙串）

  • 在密码输入面板勾选「💾 保存到钥匙串」，Zipease 会使用 macOS 原生 Keychain（钥匙串）加密保存，加密密钥由 Apple Secure Enclave 硬件保护。
  • 到「设置 → 通用 → 管理保存的密码」可查看 / 删除已保存的条目。
  • 即使启用 iCloud 钥匙串同步，开发者也无法读取任何内容——这是系统的隔离保障（详见隐私政策）。
  • 启用 7Z「文件名加密」的归档，预览列表本身也需要密码才会显示。这是最高强度的保护。

🛠 六、高级：损坏归档的测试与修复

当你遇到解压报错或怀疑压缩包损坏时，可直接使用 Zipease 内置的测试与修复功能，无需另装工具。

6.1 测试归档完整性

在预览面板顶部工具栏点击「测试」，Zipease 会逐文件做 CRC 与解包校验并汇总「通过 / 损坏 / 密码错误」三项统计，对大归档非常实用。

6.2 修复损坏压缩包

1

预览面板点「修复」，或菜单「工具 → 修复压缩包…」。

2

选择修复强度：仅检测 / 检测并修复。7Z/ZIP 会尝试恢复可用数据，RAR 转 7Z 结构重建。

3

修复完成后选择「保存修复后的文件」写入目标位置，可直接打开检查恢复出的内容。

💡

关于分卷包（.zip.001 / .7z.001 / .part1.rar）：请确保所有分片齐全、处于同一文件夹、命名方式与原始完全一致，然后直接打开首片即可自动识别并处理。缺片时会给出「分卷缺失」提示。

💎 七、Pro 版：购买、恢复与已购买状态

7.1 Pro 版解锁能力

  • 🔐 加密压缩（ZIP ZipCrypto / 7Z AES-256）
  • 🗂 7Z 格式压缩 + 文件名加密
  • 📦 批量处理（批量解压 + 批量压缩）
  • 🩹 损坏归档修复 与编码乱码修复
  • 🔑 密码钥匙串管理（保存 + 自动填充）
⚡️

一次性买断 · 终身授权 · 无自动扣费：购买后终身免费升级后续所有新格式、新功能。可在 App Store「订阅」中核实无任何续订记录。

7.2 购买流程

1

打开任一 Pro 功能（加密压缩、批量处理等），会弹出「升级 Pro」窗口，或进入设置 → 通用底部点「立即购买」。

2

点击「购买 Pro 永久版」按钮，按 Apple 标准流程使用 Face ID / Touch ID / 密码完成支付。

3

支付成功后，应用会立即解锁所有高级功能，底部按钮变为「✅ 已购买」。

7.3 恢复购买（换机 / 重装 / 审核关键）

  • 进入设置 → 通用，在主按钮下方始终可见「恢复购买」按钮（Guideline 3.1.1 强制要求，即使已解锁也会显示）。
  • 点击后会使用当前登录的 App Store 账号查询历史交易记录，找到对应买断订单后自动恢复 Pro 状态。
  • 换机、重装、从家庭共享迁移时，请先使用当时购买的 Apple ID登录 App Store 再执行恢复。
